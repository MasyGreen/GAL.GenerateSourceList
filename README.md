# Назначение

Создание реестра исходных кодов форм\отчётов\функционала Галактика ERP

Формируется файл по шаблону [Текущая дата][_][Текущее время][ ][Реестр ресурсов.xlsx], например: **20251231_10-24-59 Реестр ресурсов.xlsx**

*Примечание: если каталог начинается с 'OFF' или содержит слово 'Отключено' строка результата помечается цветом*

## Параметры

Файл параметров **config.json** создается автоматически при первом запуске 

```json
{
  "folder_process": "d:\\Work\\", 
  "folder_result": "d:\\Work\\",
  "show_skip": false,
  "use_diff": true,
  "ext_vip": true,
  "ext_slk": true,
  "ext_rtf": true,
  "ext_gcd": true,
  "ext_fr3": false
}
```

|    Параметр    | Назначение                                                                        | 
|:--------------:|:----------------------------------------------------------------------------------|
| folder_process | Каталог верхнего уровня с исходными кодами                                        |
| folder_result  | Каталог для файла-результата                                                      |
|   show_skip    | Показывать в журнале пропущенные файлы                                            |
|    use_diff    | Анализировать файлы: #DEFRES*.*                                                   |
|    ext_vip     | Анализировать файлы: vip, frm                                                     |
|    ext_slk     | Анализировать файлы: slk                                                          |
|    ext_rtf     | Анализировать файлы: rtf                                                          |
|    ext_gcd     | Анализировать файлы: gcd (докомпиляция словаря)                                   |
|    ext_fr3     | Анализировать файлы: fr3 (отладка, ожидается, что для всех *.fr3 есть #DEFRES*.*) |

# Cтруктура каталогов

Ожидается, что исходные коды доработок, относительно каталога верхнего уровня, сгруппированы в каталоги проектов.

Каждый проект содержит:

* один каталог **v_last** содержащий актуальную версию доработки

* один файл **name.bat** определяющий имя выходного ресурсного файла

```commandline
set DEBUGNAME=ResName
```
* опционально, один или несколько файлов **#DEFRES\*.***

Пример структуры каталогов от **s:\\VIP910\\**:

```

├───13 Export
│   ├───v_last
│   │      #DEFRES_1301.001
│   │      #DEFRES_1302.001
│   │      Const.vih
│   │      ImpExp.vip
│   │      name.bat
│   │      prj.prj
│   │      Table.vih
│   │      _DelTempRename.bat
│   │      _project.vpr
│   │
│   └───_Данные заказчика
│           Шаблон_.xls
└───Tune
    └───v_last
            #DEFRES_Tune.001
            galadsi.txt
            MartTune.vip
            MartTune_.res
            name.bat
            prj.prj
            _DelTempRename.bat
            _project.vpr

```

# Анализируемая информация

Информация собирается из файлов **#DEFRES\*.*** и файлов исходных кодов, по возможности объединяется в одну строку 

Дополнительная информация из файлов **#DEFRES** сворачивается с данными из исходников по полям _CATALOG + _NAMEFORM

Из исходных кодов поле 'Примечание' дополняется:

* для gdc - списком таблиц
* файл расширения настроек - списком настроек

## Теги

Используемые теги, начинаются с **#** до пробела:

|    Тег     |          Назначение           |
|:----------:|:-----------------------------:|
| #DEVELOPER |          Разработчик          |
|  #CLIENT   |           Заказчик            |
| #NAMEFORM  |         Наименование          |
| #STARTPATH |         Путь запуска          |
|    #DO     | Документ основнаие разработки |
|   #CODE    |        Код разработки         |
|   #HOUR    |     Трудозатраты в часах      |
|   #PRIM    |          Примечание           |

### Пример файла **#DEFRES\*.***

Теги указываются в любом порядке построчно, например:

```
#DEVELOPER Разработчик доработки
#CLIENT Зам. нач. отдела сбыта - Иванов П. С.
#NAMEFORM TXOAPI. Распределения затрат
#STARTPATH ARD
#DO Дог. №500 от 01.01.2030 г., Заявка №35-18
#CODE 1204.07
#HOUR 64
#PRIM Запуск функции распределения затрат
```

### Пример использования тегов в исходном коде

Теги указываются в комментариях и документации с префиксом **#DEFRES**, например:

```

!#DEFRES #DEVELOPER Март-Консалтинг

//#DEFRES #CLIENT Зам. нач. отдела сбыта - Иванов П. С.

/*
#DEFRES #NAMEFORM TXOAPI. 12 Распр. цех., хоз. затрат (ПЗ)
*/

#doc
#DEFRES #DO Общий компонент
#end
```

|                                                           -                                                           | Дополнительно может потребоваться выбрать шаблон Excel\FastReport, Имя Шаблона                                 |

|                                                     VIP AltedDIC                                                      | Докомпиляция словаря                                                                                           |
|                                                         Tune                                                          | Просомотр: Модуль - Настройка - Настройка (настройки могут быть пользовательские и системные см. Документацию) |
|                                                           -                                                           | Инициализация: Настройка - Администратор - Проверка реестра настроек (выделить все элементы)                   |

|                                                    AlterInterface                                                     | Расширение визуальных форм                                                                                     |
|                                                       Interface                                                       | Пользовательский интерфейс\алгоритм. Запуск RunAnyView и т.п.                                                  |
